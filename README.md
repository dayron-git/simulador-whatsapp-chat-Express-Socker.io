# simulador-whatsapp-chat
Simulador de interfaz del chat de whatsapps

##Instrucciones
-Abra solamente el archivo pa4-dayronLozano
-Verifique que tiene Node.js instalado "node -v"
.Como ya existe package-lock.json, corré 'npm ci --ignore-scripts' en vez de 'npm init' y 'npm i'. Esto instala exactamente las versiones que verificamos recién (express 5.1.0, socket.io 4.8.1 y sus sub-dependencias), sin ejecutar ningún script automático de instalación.
-Instalá nodemon como dependencia de desarrollo del proyecto: 'npm install --save-dev nodemon --ignore-scripts'
-Ejecutar proyeto "npm start"

-Para finalizar el proyecto presione "Ctrl + c"
